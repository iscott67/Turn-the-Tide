# Phase 1 Scope

## Goal
Create a reliable digital inventory of the user's actual home bar and turn that inventory into practical buying and capability intelligence.

## Core jobs
1. Capture the bar quickly.
2. Correct AI mistakes without frustration.
3. Know what is available, low or needs replacement.
4. Maintain a useful purchase list and wishlist.
5. Show which cocktail families the bar supports.
6. Recommend the highest-leverage next additions.

## Deliberately deferred
Cocktail recommendations, taste learning, Cocktail Memory and the full 300-recipe library belong to later phases. The 70-recipe capability library is included only to make Bar IQ useful now.
