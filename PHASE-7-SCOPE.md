# Phase 7 — Scanner Journey

## Version
3.3.10-dev

## Objective
Make shelf scanning understandable within five seconds and reduce the interface to one clear action at each stage.

## Included
- Three-stage Photos, Analyse and Confirm journey
- One primary action during photo capture
- Clear one-to-three-photo guidance
- Dedicated AI working screen
- Stage-specific progress language
- 45-second timeout and Cancel Scan
- Confidence summary
- Card-based bottle confirmation
- High, medium and low-confidence treatment
- Editable name, brand and type
- Add Missed Bottle
- Duplicate protection when saving
- Cleaner return to My Bar after confirmation

## Technical constraint
Recognition still begins after the user submits the photo set. This release does not claim continuous or live camera recognition.
