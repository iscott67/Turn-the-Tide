# Turn the Tide Release Notes

## 3.2.0-dev — Beautiful release

This release concentrates on polish rather than new intelligence.

### Home
- Refined the welcome hierarchy, spacing and typography.
- Added small context chips for time of day, local conditions and taste learning.
- Added a capability card showing:
  - Ready now
  - One bottle away
  - Shopping-list count
- Improved quick actions and primary recommendation presentation.

### Screens and cards
- Standardized spacing, card radii, shadows and screen introductions.
- Reduced visual weight while preserving strong hierarchy.
- Improved inventory rows, Bar IQ additions, scanner guidance and shopping presentation.
- Added more consistent press states and restrained screen transitions.

### Scanner
- Added dynamic guidance beneath the shelf thumbnails.
- Clarified how many photos remain before a shelf is ready to analyse.

### Navigation
- Preserved the corrected five-item primary navigation:
  - Home
  - Scan
  - My Bar
  - Taste
  - Bar IQ
- Retained the structured hamburger menu and colour themes.

### Version
- Updated application, assets and service-worker cache to 3.2.0-dev.
